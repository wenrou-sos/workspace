# 麦克风换电 / 充电调度系统

针对 KTV / 酒吧等场所：根据每支麦克风的**使用时长、当前电量、健康度**，
结合**有限充电位、少量备用电池、营业高峰时段**，自动安排换电顺序，
并在临时换机、设备故障、耗电异常后重新排程，同时提供低电量预警。

## 快速运行

```bash
python3 -m mic_scheduler.demo              # 端到端演示（含 3 类突发事件）
python3 -m unittest discover -s tests -v   # 单元测试（15 个）
```

## 演示场景

8 支麦克风、3 个充电位、4 块备用电池，营业时间 18:00–02:00（高峰 20:00–23:30），
开班前各麦电量 20%~78% 不等。运行中注入三个真实事件：

| 时间 | 事件 | 系统反应 |
|---|---|---|
| 19:30 | 客人嫌 M2 电量低，要求提前换机 | 临时取备电更换 → 作废旧计划 → 基于新现场整体重排 |
| 21:00 | M6 机身故障，启用备用机身 M6' | 电池不换、转移到新机身，使用计划与剩余换电计划迁移 |
| 22:30 | M5 电池老化突发放电（2.2 倍速） | 更新耗电系数 → 重排，M5 的换机时间自动提前 |

## 四个难点的对应实现

### 1. 电量消耗模拟 —— `battery.py`
- 三档耗电：使用中（约 6 小时耗尽）/ 待机（约 24 小时）/ 关机（约 48 小时）；
- 每块电池带 `health`（老化掉电更快）、每台设备带 `drain_scale`（漏电/故障）；
- 充电曲线先恒流（0→80% 约 72 分钟）后恒压（80%→100% 变慢）；
- `time_to_empty()` 不是线性估算，而是**按未来使用计划逐分钟积分**，
  能正确处理"两批客人之间待机 1 小时"这类使用片段；
- 3% 电量作为保护截止阈值（对应锂电截止电压）。

### 2. 有限充电位分配 —— `pool.py` + `planner.py`
- **READINESS 策略（营业中）**：soc 最接近可用阈值的电池优先占充电位，
  保证任何时刻都尽快产出"即取即用"的备电，低电电池让位排队；
- **BALANCED 策略（歇业后）**：最低电量优先、先到先充，轮流深充保健康；
- 计划器不是静态查表，而是把每个候选换机时刻放进**影子仿真**完整快放，
  只有"按顺序执行时确实能取到达标备电、且不挤掉别人的电池"才算可行，
  从根上避免"两个计划各自可行、合在一起抢同一块电池"。

### 3. 临时换机后的计划调整 —— `planner.py`（EDF 贪心 + 全局重放）
- `SwapPlanner.replan(scene)` 每次都从**当前现场**重新生成全量计划，
  因此临时换机、换机身、改耗电系数后调用一次即可，不需要修补旧计划；
- 核心循环：影子快放找最早断电的麦 → 在断电前的时间窗内逐分钟评分：
  - 落在高峰：重罚（+60）
  - 高峰前 30 分钟（避峰窗口）：奖励（-18）
  - 与其他换机间隔 < 30 分钟：线性惩罚，避免服务员扎堆、备电瞬时掏空
  - 同一支麦两次换机至少间隔 90 分钟，防止"刚换上的满电又被换下"
- 顺序执行导致的备电落空会被自动检测、删条、按真实断电时刻重排；
- 备电分三档兜底：满电(≥80%) → 应急半电(≥50%，给出提示) →
  强制换机(取池中最高电量电池，绝不让包厢断电，并报警)。

### 4. 低电量预警 —— `monitor.py`
- **CRITICAL**：30 分钟内预计断电；**WARNING**：60 分钟内；
- 预测考虑未来使用计划（待机时段会自动延后预警）；
- 高峰中/高峰前 60 分钟满电备电少于 2 块时报警，并给出"下一批备电几分钟可用"；
- 预警去重，临时换机后该麦允许重新触发（状态变了，旧预警失效）；
- 计划器另有"30 分钟内 ≥3 次换机"的集中度提示。

## 代码结构

```
mic_scheduler/
├── models.py    # Battery / Microphone / UsageSegment / ChargingPool / Scene
├── battery.py   # 耗电三档、CC-CV 充电、TTE 积分预测
├── pool.py      # 充电位分配（READINESS / BALANCED）、备电就绪时间推演
├── engine.py    # 离散时间推进、换机、断电登记、计划校验快放
├── planner.py   # 换电计划：影子重放 + EDF 贪心 + 时段成本评分 + 三档兜底
├── monitor.py   # 低电量/备电不足预警（去重 + 换机后重置）
└── demo.py      # 晚市场景端到端演示（含临时换机/换机身/耗电突增）
tests/
└── test_scheduler.py
```

## 设计要点

- **时间粒度 1 分钟**，用深拷贝现场做"影子推演"，规划逻辑绝不触碰真实状态；
- 所有成本权重集中在 `planner.py` 顶部（`PEAK_PENALTY`、`SPREAD` 等），
  可按门店实际人力/备电数量直接调；
- 非线性锂电曲线可在 `battery.py` 的 `DRAIN_PER_MIN` 处替换为 soc 查表，
  其余模块接口不变。
